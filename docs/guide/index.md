# 介绍

## Todot Engine 是什么？

Todot Engine 是一个基于 Three.js 构建的现代 3D 游戏引擎，专为 Web 平台设计。它提供了一套完整的工具和 API，使开发者能够轻松创建高质量的 3D 游戏和交互式应用。

引擎的核心特性包括：

- **节点系统**：基于层次结构的场景图，便于组织和管理游戏对象
- **组件系统**：灵活的组件架构，允许通过组合不同组件来构建复杂的游戏对象
- **渲染系统**：支持 WebGL 和 WebGPU，提供高性能的渲染能力
- **物理系统**：集成 Cannon.js 物理引擎，支持刚体动力学和碰撞检测
- **粒子系统**：强大的粒子效果系统，支持各种视觉效果
- **输入系统**：统一的输入处理机制，支持键盘、鼠标和触摸输入
- **地形系统**：高效的地形生成和编辑工具
- **动画系统**：支持骨骼动画和关键帧动画

## 为什么选择 Todot Engine？

- **易于学习**：如果你熟悉 Three.js，你会发现 Todot Engine 的 API 设计非常直观
- **高性能**：针对现代 Web 浏览器优化，支持 WebGPU 以获得更好的性能
- **灵活性**：模块化设计允许你只使用你需要的功能
- **可扩展性**：开放的架构设计，便于扩展和定制

## 谁适合使用 Todot Engine？

- **游戏开发者**：想要创建 3D 网页游戏的开发者
- **Web 开发者**：需要在网站中添加复杂 3D 交互的开发者
- **教育工作者**：希望创建交互式 3D 教学内容的教育工作者
- **可视化专家**：需要创建数据可视化或科学可视化的专业人士

## 技术架构

Todot Engine 采用了分层架构设计：

1. **核心层**：提供基础功能，如场景管理、节点系统和渲染管线
2. **系统层**：包括物理系统、粒子系统、输入系统等功能模块
3. **工具层**：提供辅助工具，如调试工具、性能监控等
4. **API 层**：向开发者暴露统一的接口

这种架构设计使得引擎既易于使用，又具有良好的可扩展性和可维护性。
